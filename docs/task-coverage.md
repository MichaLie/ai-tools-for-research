# Task-coverage map — AI Tools for Scientific Research

Generated from the catalog data: 176 tools, 35 task categories; newest verification 2026-08-18.
Purpose: input for external gap-hunting — which academic/research tasks
augmentable by AI are NOT yet represented below?

Scope rules: research workflow only — teaching/grading and general office admin
are deliberately excluded. Depth areas covered by companion indexes (not this
catalog): biological foundation models, autonomous science agents at scale,
privacy-first coding/data agents (https://michalie.github.io/).

### Systematic Review & Evidence Synthesis (10 tools)
Task: screen thousands of abstracts, extract evidence, and keep a review living — PRISMA-style.
Specific use cases already covered:
- transparent, simulatable machine-learning screening you can audit and run offline — the only open-source option with a validation/simulation framework
- regulatory-grade, fully audit-trailed AI extraction and screening quality control (pharma/medical-device evidence requirements)
- AI-suggested extraction designed for the living-review-to-guideline pipeline (GRADE ecosystem via Evidence Prime)
- living systematic reviews with auto-updating searches plus publishable interactive synthesis visualizations

### Staying Current (5 tools)
Task: keep up with new papers without reading feeds all day — trained, personalized monitoring.
Specific use cases already covered:
- Building your own trainable literature-triage model — a personal classifier for systematic monitoring/curation, not just a keyword alert; free from NIH
- One digest covering journals, preprints AND clinical-trial registrations, each item compressed to a single machine-written highlight sentence
- Mobile-first commute-friendly literature feed — audio papers and translated summaries make it the 'podcast your feed' option
- An open academic-built personal recommender you train by voting on papers, spanning preprint servers plus ML/CV/NLP conference proceedings — with a conference planner nothing else offers
- Tracks NIH grant awards alongside papers — monitoring who just got funded in your field, not only who just published

### Transcription & Qualitative Analysis (8 tools)
Task: turn interviews and focus groups into text, then into coded themes — with sensitive data kept safe.
Specific use cases already covered:
- EU-hosted transcription with an optional professional human-correction tier for verbatim accuracy — the step between DIY Whisper and a transcription bureau
- Offline transcription that hands off straight into CAQDAS software with linked timestamps — audio playback from inside the coding environment
- AI-conducted voice interviews — an avatar interviewer collects qualitative data autonomously, then the same platform analyzes it; no other vetted tool covers AI-led data collection
- AI code suggestions embedded in the standard institutional coding workflow — keeps the audit trail and codebook of classic CAQDAS while accelerating first-pass coding
- GDPR-safe transcription of sensitive interview data — nothing leaves the machine, with transcript conventions (pauses, overlap, disfluencies) built for qualitative social research
- Zero-cost, transparent AI-assisted qualitative coding — inspectable prompts plus a free EU academic LLM backend (Blablador) that stores no data; supports REFI-QDA exchange with commercial CAQDAS

### OCR & Document Digitization (7 tools)
Task: turn handwriting, archives, equations and PDFs into editable, analyzable text and LaTeX.
Specific use cases already covered:
- Fully open-source, self-hosted HTR with owned models and data — no per-page credits, works for right-to-left and non-Latin scripts via kraken
- Digitizing modern research handwriting (lab notebooks, field notes) with an explicit no-training-on-your-data policy — a privacy fit for unpublished data
- Local, batch, no-cloud conversion of entire paper libraries to structured Markdown — data never leaves the machine
- STEM-specific OCR — equations, handwritten math, and chemical structures to compilable LaTeX; sole representative of the 'get this formula out of a PDF' task
- Peer-review-backed LLM transcription workflow: the accompanying study found LLMs beat specialized HTR (Transkribus) on 18th/19th-c. English documents — the easter egg of this area
- Training a custom HTR model on one archive's specific handwriting, then batch-transcribing the collection — the standard platform for this in digital humanities

### Lab Bench & Protocols (5 tools)
Task: draft, troubleshoot and execute protocols at the bench — hands-free, robot-ready, reagent-smart.
Specific use cases already covered:
- Antibody/reagent selection grounded in AI-decoded published figures — directly attacks the antibody reproducibility crisis; nothing else in the catalog covers reagent choice
- Conversational agent acting over lab inventory and sample records (the inventory/ordering AI slot), or null if judged too close to generic ELN AI
- Natural language to lab-robot protocol code — the only bench-automation entry point a student can try without hardware
- AI-assisted authoring and troubleshooting of citable, versioned wet-lab protocols in the community-standard protocol repository (23,000+ public protocols)
- AI parsing of legacy PDF SOPs into structured, executable ELN templates

### LaTeX & Academic Language (5 tools)
Task: AI inside the scholarly writing toolchain — LaTeX editing, published-language feedback.
Specific use cases already covered:
- A full AI-first LaTeX editor free with any ChatGPT account — the whole-document AI context (not per-sentence) plus built-in arXiv literature agent
- LaTeX error diagnosis and repair inside the editor 20M+ researchers already write in — no copy-pasting code into a chatbot
- AI-assisted scholarly writing that never sends data to the cloud (local models, local compile) — the GDPR/sensitive-data option; also the only AI-assisted Typst workflow found
- Batch proofreading of a whole .tex manuscript outside any editor, with tracked-changes Word output co-authors can review — bridges LaTeX and Word-based collaborators
- Sentence-level feedback calibrated to published-paper conventions rather than general English; corrections applied directly within LaTeX source code

### AI Manuscript Review & Disclosure (11 tools)

### Integrity Screening & Forensics (6 tools)
Task: screen the literature — and your own reference list — for fabrication, manipulation and AI-generated text.
Specific use cases already covered:
- retraction-risk screening of references plus proactive retraction-cascade alerts
- Cross-paper figure matching against 150M+ published figures, purchasable as a EUR 29 one-off scan — no publisher subscription needed (Proofig's catalog entry is manuscript-level screening)
- AI-text detection with the only independently evaluated sub-0.5% false-positive rate — usable for editorial screening where accusation stakes are high
- The only public tool for checking whether a specific published paper is flagged for tortured phrases, mass-produced text, or reliance on retracted work — post-publication integrity screening for readers, not publishers
- Semantic citation verification — whether the cited paper supports the claim, not merely whether the reference exists (scite shows citation context but does not classify your own manuscript's claims)
- recomputation-based consistency check of reported statistics — a spellchecker for stats

### Patents & Tech Transfer (6 tools)
Task: prior-art checks, patent landscapes and invention disclosures. Caution: unfiled inventions are confidential — check your TTO's policy before pasting disclosure text into third-party AI.
Specific use cases already covered:
- Chemistry-aware prior-art search over curated substance/Markush indexing — inside a database most chemistry-active universities already license, so no new procurement
- Zero-cost first-look prior-art check with priority-date-aware 'Find prior art' across patents, Scholar and Books simultaneously
- AI drafting of the invention disclosure itself, aimed explicitly at university researchers and tech transfer — the only researcher-facing (not attorney-facing) drafting tool found Real but young company; no independent academic adoption found; no free tier. Confidentiality caution: check TTO policy before pasting unfiled invention details into third-party AI (UC Berkeley OTL advises exactly this)
- TTO-grade commercial landscape triage — 'who is active in this space and is it heating up' — before deciding to file
- Free, open-source semantic prior-art search an academic can run before submitting an invention disclosure; API is explicitly pitched at university tech transfer offices
- Seeing which patents cite your own papers, and finding biological sequences buried in patents (PatSeq) — the scholarly-patent bridge no general assistant or single-corpus tool covers

## What a proposed addition must satisfy

1. Maps to a research-workflow task; 2. usable this week (no waitlist/demo-only);
3. does something a general assistant (ChatGPT/Claude/Gemini) cannot do well;
4. real organization, privacy policy, transparent pricing; 5. alive and maintained.
Proposals should name the TASK first, then candidate tools with URLs. Working URLs
and honest uncertainty expected — unverifiable claims are useless.
