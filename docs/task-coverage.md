# Task-coverage map — AI Tools for Scientific Research

Generated from the catalog data: 177 tools, 35 task categories; newest verification 2026-10-15.
Purpose: input for external gap-hunting — which academic/research tasks
augmentable by AI are NOT yet represented below?

Available coverage counts active entries only. Pending and unconfirmed tools
are listed separately; retired tools do not fill a current task gap.
Examples use current descriptions, not historical discovery notes.

Scope rules: research workflow only — teaching/grading and general office admin
are deliberately excluded. Depth areas covered by companion indexes (not this
catalog): biological foundation models, autonomous science agents at scale,
privacy-first coding/data agents (https://michalie.github.io/).

## Current task coverage

### General-Purpose AI Assistants (8 active tools)
Task: an everyday thinking partner — drafting, summarizing, coding help, quick analysis at any stage of research.

Available examples:
- [ChatGPT](https://chatgpt.com/) (core) — Draft, research, analyze uploaded data, and create images in ChatGPT. Deep Research produces source-linked reports; free access includes limited file and image capabilities, with higher usage limits on paid plans.
- [Claude](https://claude.ai/) (core) — Read and draft documents, search the web, create files, and run code with Claude. Free access has usage limits; paid plans add Claude Code, Claude Science, and integrations with Chrome and Microsoft 365.
- [Gemini](https://gemini.google.com/) (core) — Analyze documents and multimodal inputs, draft text, and research questions with Google’s AI assistant. Deep Research combines web sources and optional connected Workspace content into reports; free and paid plans have different limits.
- [Google AI Studio](https://aistudio.google.com/) (extended) — Experiment with Gemini prompts and models in a browser, prototype applications, and obtain code for API integration. Web-workspace access and API usage have separate limits and pricing considerations.
- [Grok](https://grok.com/) (extended) — Ask questions, write code, and create images with an assistant that draws on the web and X for current information. Free access and paid subscriptions offer different usage limits.
- [LM Council](https://lmcouncil.ai/) (extended) — Compare responses from multiple language models and let models discuss a question with one another. Useful for examining how different systems approach the same research or writing task.
- [Microsoft Copilot](https://copilot.com/) (core) — Ask questions and create images, documents, spreadsheets, and presentations with Microsoft Copilot. Available capabilities depend on the signed-in account, subscription, and organizational settings; work and school accounts can connect organizational content.
- [Vibe (Mistral, formerly Le Chat)](https://chat.mistral.ai/) (extended) — Mistral’s Vibe, formerly Le Chat, supports chat, connected work tasks, and coding. Free access includes limited web searches and coding sessions; paid plans raise limits and add document creation capabilities.

Task: find, screen and synthesize papers beyond what you can read yourself.

- [Elicit](https://elicit.com/) (core) — Find papers, screen studies, extract data, and produce research reports with AI-assisted evidence workflows. Researchers can customize covered studies and extraction questions; free access and paid plans serve different workloads.

- [Scite](https://scite.ai/) (core) — Smart Citations platform showing whether later papers support, contrast, or merely mention cited work. 1.6B+ citations from 317M+ full-text articles, classified by deep learning to evaluate how a claim, paper, or author has been received.
- [Semantic Scholar](https://www.semanticscholar.org/) (core) — Find scholarly literature with AI-assisted search, TLDR summaries, citation relationships, and Semantic Reader for supported papers. Free access and a developer API support literature discovery and research applications.

Pending or unconfirmed — excluded from available coverage:
- [Literature Insights (Gemini for Science)](https://labs.google/science) (candidate) — Chat interface over scientific literature that builds structured tables with custom searchable attributes for side-by-side comparison and generates reports, slide decks, infographics and audio/video overviews. ### Systematic Review & Evidence Synthesis (10 active tools)
Task: screen thousands of abstracts, extract evidence, and keep a review living — PRISMA-style.

Available examples:
- [ASReview](https://asreview.nl/) (core) — Runs active-learning screening locally: the model learns from your include/exclude decisions and reorders remaining records, with simulation mode to benchmark savings on your own dataset. Fully open source; data never leaves your machine.
- [citationchaser](https://estech.shinyapps.io/citationchaser/) (core) — Forward and backward citation chasing via the Lens.org API: input known relevant articles, retrieve everything they reference and everything citing them, and download all lists as RIS for systematic-review identification.
- [Covidence](https://www.covidence.org/) (core) — Manages the full PRISMA pipeline in one workspace: import, dedupe, dual screening, full-text review, data extraction, and quality assessment, with team roles and export to analysis. De-facto standard licensed by many university libraries.
- [DistillerSR](https://www.distillersr.com/) (extended) — Runs audit-trailed literature reviews at regulatory grade: AI reranking of references, automatic study classifiers, generative extraction linked back to source text, and error-checking of human screening decisions, all with traceable human-in-the-loop validation.
- [Laser AI](https://www.laser.ai/) (extended) — Extracts data from study PDFs by suggesting text passages and table values for reviewer confirmation, deduplicates references, and standardizes screening with reusable guides and vocabularies; built for living evidence synthesis feeding guideline pipelines.
- [Nested Knowledge](https://nested-knowledge.com/) (core) — Combines screening (Robot Screener), smart tagging, meta-analytical extraction, and PRISMA reporting with living-review updates: searches re-run automatically and interactive evidence maps and synthesis visualizations stay current and shareable.
- [Polyglot (TERA)](https://tera-tools.com/) (core) — Translates a PubMed or Ovid MEDLINE search string into syntax for Embase, CINAHL, PsycINFO, Scopus, Web of Science, Cochrane and more. Part of Bond IEBH's TERA evidence-synthesis suite (SearchRefiner, Deduplicator, Screenatron, Disputatron).
- [PubReMiner](https://hgserver2.amc.nl/cgi-bin/miner/miner2.cgi) (extended) — Runs a PubMed query and returns frequency tables of journals, authors and words in the result set — for refining search terms, finding active experts, or choosing a target journal.
- [Rayyan](https://www.rayyan.ai/) (core) — Screen abstracts and full texts independently with blinded reviewer decisions, AI relevance ranking, and conflict resolution; deduplicate records and extract study data within a shared review. A free tier supports basic screening.
- [Yale MeSH Analyzer](https://mesh.med.yale.edu/) (extended) — Paste up to 20 PMIDs to get a side-by-side grid of each article's MeSH headings, subheadings, major-topic flags and author keywords; exports Excel or HTML for building search strategies.

### Staying Current (5 active tools)
Task: keep up with new papers without reading feeds all day — trained, personalized monitoring.

Available examples:
- [LitSuggest](https://www.ncbi.nlm.nih.gov/research/litsuggest/) (core) — Train a personal machine-learning classifier by marking PubMed articles relevant or irrelevant; the system then scores new PubMed papers, sends an automated weekly digest per project, and supports shared collaborative curation.
- [Paper Digest](https://www.paperdigest.org/daily-paper-digest/) (extended) — Daily email digest of new papers from arXiv, PubMed, bioRxiv, medRxiv and ClinicalTrials.gov, filtered by user-set areas, keywords and authors, with a machine-generated one-sentence summary per paper and impact-based ranking.
- [R Discovery](https://discovery.researcher.life/) (core) — Personalized reading feed over 250M+ papers: set research interests, get daily article recommendations and new-paper alerts, listen to audio versions, translate papers into 30+ languages, and chat with PDFs on mobile or web.
- [Scholar Inbox](https://www.scholar-inbox.com/) (core) — Daily or weekly digest of new arXiv, bioRxiv, chemRxiv and medRxiv papers ranked by a recommender trained on the user's own ratings; includes semantic search, figure-preview skimming, collections, and a conference poster-session planner.
- [Stork](https://www.storkapp.me/) (extended) — Enter keywords and authors once; receive daily or weekly email alerts of matching new papers and preprints from PubMed and other sources, plus NIH grant-award alerts, with optional in-email translation of titles and abstracts.

### Survey & Experiment Design (4 active tools)
Task: design instruments and experiments well before collecting a single data point — including simulated piloting.

Available examples:
- [Expected Parrot](https://www.expectedparrot.com) (core) — Open-source Python DSL for building surveys and experiments, running them on panels of LLM-simulated respondents across many models, then re-fielding the identical instrument to real humans ('Humanize') and analyzing both in one results object.
- [NC3Rs Experimental Design Assistant](https://eda.nc3rs.org.uk/) (core) — Free web tool where researchers diagram an in vivo experiment and receive automated bespoke critique: statistical-method recommendations, randomization and blinding support, sample-size calculation, and a shareable design report for funders and ethical review.
- [Qualtrics AI](https://www.qualtrics.com/support/survey-platform/distributions-module/synthetic-panels/) (core) — Create and evaluate surveys in Qualtrics, including simulated responses through Synthetic Panels. The documented panel represents the United States general population; availability depends on institutional licensing and enabled features.
- [Synthetic Users](https://www.syntheticusers.com/) (extended) — Runs no-code simulated qualitative studies: multi-agent AI participants with persistent persona profiles answer interviews, concept tests, and usability-style questions in minutes, at $2-60 per interview instead of recruiting humans.

Pending or unconfirmed — excluded from available coverage:
- [PowerGPT](https://power-gpt.net/) (candidate) — Conversational power-analysis assistant wired to statistical engines: guides test selection and computes a priori sample size for t-tests, ANOVA, proportions, chi-square, Cox, logrank. Free, pick your institution or 'Other Institutions'; no login.
- [Protocol Builder](https://protocolbuilderpro.com/) (candidate) — Drafts clinical research protocols and informed-consent forms section-by-section from institutional templates; the built-in AI assistant completes sections, generates consent drafts from protocol text, and rewrites consent language at an 8th-grade reading level.

### Transcription & Qualitative Analysis (8 active tools)
Task: turn interviews and focus groups into text, then into coded themes — with sensitive data kept safe.

Available examples:
- [Amberscript](https://www.amberscript.com/en/business-solutions-use-cases/transcription-services-qualitative-research/) (extended) — Cloud transcription for research interviews: machine drafts in minutes (90+ languages, ~85% accuracy) or human-verified transcripts (>99%, 18+ languages) with NDA-bound transcribers. Data stored only in Western Europe; GDPR, ISO 27001/9001. Word/TXT export, speech-to-text API.
- [aTrain](https://business-analytics.uni-graz.at/en/research/atrain/) (extended) — Offline transcription of speech recordings with speaker detection (faster-whisper, 57 languages); exports transcripts with clickable timestamps directly importable into ATLAS.ti and MAXQDA. Installs from the Microsoft Store; no data ever sent to the internet.
- [Evidano](https://www.evidano.com/) (core) — Uploads interview transcripts, documents, audio/video and runs thematic analysis with supporting quotes, frequency and cross-segment analysis, plus a chatbot over the data. Also fields an AI avatar that conducts semi-structured voice interviews in 100+ languages. Free tier available.
- [MAXQDA AI Assist](https://www.maxqda.com/products/ai-assist) (core) — AI add-on inside the MAXQDA CAQDAS: suggests codes and subcodes for text passages with explanatory comments, summarizes documents and coded segments, and answers questions about coded data with responses linked to text sections. Claims zero data retention and EU-based processing.
- [Montreal Forced Aligner](https://github.com/MontrealCorpusTools/Montreal-Forced-Aligner) (extended) — Command-line forced aligner built on Kaldi: time-aligns transcripts to audio at word and phone level using pretrained or self-trained acoustic models. MIT-licensed; installed via conda-forge; v3.0 cited (2026).
- [noScribe](https://noscribe.de/en/) (core) — Transcribes interview audio fully offline on the researcher's own computer using Whisper plus pyannote speaker diarization; marks pauses, overlaps and filler words per qualitative-research conventions; includes an audio-aligned correction editor. ~60 languages; Windows/macOS/Linux.
- [QualCoder](https://qualcoder.org/) (core) — Code and analyze qualitative text, PDFs, images, audio, and video in an open-source desktop tool. Optional AI-assisted coding and data chat use configurable model backends and an editable prompt library.
- [WebMAUS](https://clarin.phonetik.uni-muenchen.de/BASWebServices/interface/WebMAUSGeneral) (extended) — Web service for forced alignment: upload audio plus transcript, receive phone- and word-level time-aligned Praat TextGrid output. Munich Automatic Segmentation (MAUS) engine within the BAS/CLARIN speech-tools suite.

One keyboard shortcut turns any on-screen formula into paste-ready code.
- [Transkribus](https://www.transkribus.org/pricing) (core) — Uploads scans of handwritten or printed historical documents and gets searchable transcriptions; trains custom recognition models for a specific hand, script, or language; recognizes tables and form fields.
- [WebPlotDigitizer](https://automeris.io/) (core) — Extract numerical data from chart images and PDFs using manual tools, computer vision, and AI assistance. Supports several plot types through a browser interface; review the extracted data against the original figure.

## What a proposed addition must satisfy

1. Maps to a research-workflow task; 2. usable this week (no waitlist/demo-only);
3. does something a general assistant (ChatGPT/Claude/Gemini) cannot do well;
4. real organization, privacy policy, transparent pricing; 5. alive and maintained.
Proposals should name the TASK first, then candidate tools with URLs. Working URLs
and honest uncertainty expected — unverifiable claims are useless.
